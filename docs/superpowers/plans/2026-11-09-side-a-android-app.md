# Side A 안드로이드 앱 개발 계획 (2026-11-09 초안)

기준 문서: `docs/superpowers/specs/2026-11-07-story-audio-english-design.md` (특히 7장 화면, 8장 저장·소리, 디자인 시스템 정리).
방식: 지금 웹 코드(HTML, CSS, JS)를 Capacitor로 감싼 안드로이드 앱. 처음부터 코틀린으로 다시 짜지 않는다.

## 0. 먼저 정할 것 (성범)

1. **어떻게 깔아서 쓸지** → **A. 혼자 쓰기(직접 설치)로 정했다 (2026-11-09 성범 결정).** 플레이스토어 항목(계정 표의 Play 개발자 계정, 2장 8단계, 3장의 'B만' 항목)은 지금 하지 않는다.

   - B. 플레이스토어에 올리기: 개발자 등록비, 테스트 기간, 정책 서류가 붙는다(3장 참고). 나중에 B로 넘어가도 코드는 거의 그대로 쓴다.

## 2. 개발 순서

각 단계 끝에 성범 폰에서 직접 확인한다. 개발 중에는 폰을 선으로 연결해 고치면 바로 바뀌게(라이브 리로드) 둔다.

1. **앱 뼈대**: 앱 폴더를 새로 만들고 Capacitor를 붙인다. 지금 웹 앱이 폰에서 앱으로 열리는 것까지. 앱 이름 Side A, 아이콘(Figma 'app icon' 3종), 시작 화면(검정 바탕 가운데 막대).
2. **화면 끝까지 배경**: 위 상태 표시줄, 아래 시스템 막대를 투명하게 하고 배경을 끝까지 깐다. 글자·버튼은 막대 높이만큼 안쪽. 막대 아이콘은 흰색.
3. **새 디자인 입히기**: Figma 시안대로 글자 표, 색, 4px 간격, 모서리 기준, 홈 머리 줄(프로필과 인사말, 설정 아이콘), 앨범 화면, 재생 시트, 트랙리스트 시트, 미니 플레이어(화면 너비 막대), 설정 화면, 가사 글자 크기 3단계, 인터넷 없음 알림. 아이콘은 Lucide.
4. **백그라운드 재생**: 화면을 꺼도 다음 화까지 이어서 재생, 잠금 화면과 알림창에 재생 버튼. 안드로이드 미디어 재생 서비스를 쓰는 플러그인을 붙인다. 운동 중 실제로 1시간 이상 들어 보는 시험을 한다.
5. **소리를 R2로 옮기기**: 새 통을 만들고 지금 소리 파일을 올린다. 앱은 R2에서 받고, 들은 화와 다음 화는 폰에 저장해서 인터넷 없이도 재생. 설정의 Downloads(다음 화 받기, 와이파이에서만, 쓴 용량, 지우기).
6. **(나중에) 구글 로그인과 들은 기록**: 2026-11-09 성범 결정으로 지금은 하지 않는다. 처음에는 들은 기록을 폰 안에만 저장하고, 이 단계는 앱이 다 된 뒤 필요할 때 한다. 할 때 내용: Firebase Authentication 구글 로그인과 Firestore 문서(화마다 들은 위치, 다 들음, 들은 시간), 로그인 전에는 폰에만 저장하고 로그인하면 합친다. Sign out.
7. **설치 파일 내기**: 서명한 APK를 만들어 폰에 깐다. 앱 모양이 바뀔 때만 다시 깐다. 대본·음성처럼 R2에서 받는 내용은 다시 깔지 않아도 바뀐다.
8. (B를 고르면) 플레이스토어 올리기: 3장 서류를 갖추고 비공개 테스트부터.

### 1단계 결과 (2026-11-09)

- 앱 폴더: `learn-english/side-a/` (Capacitor 8.6, 앱 고유 이름 `com.seongbeom.sidea`, 이름 Side A).
- 웹 코드: `npm run web`이 `spikes/episode-01/web`(build_pwa.py 결과)을 `side-a/www`로 복사하고, 서비스 워커와 설치 설정은 뺀다. 소리 파일도 지금은 앱 안에 넣는다(성범: 현재는 로컬로 넣어도 됨). R2로 옮기는 5단계는 나중에 해도 된다.
- 만들기: `side-a/`에서 `npm run apk` → `android/app/build/outputs/apk/release/app-release.apk`. Gradle은 Android Studio 안의 JDK 21(`JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"`)로 돌린다. 디버그와 배포 모두 `signing/` 키로 서명한다.
- 폰 설치: `adb install -r app-release.apk`(무선 디버깅). 아이콘과 시작 화면은 Figma 'app icon' 3종으로 `@capacitor/assets`가 만들었다(`side-a/assets/`).
- 화면 비율: Android WebView는 기본으로 viewport 폭 설정을 무시해서, 폭 411인 폰에서 화면이 시안(360)보다 작게 보였다. `MainActivity`에서 `setUseWideViewPort(true)`를 켜서 360 기준으로 꽉 차게 맞췄다(2026-11-09 성범 지적).
- 성범 폰에는 Side A가 두 개 보인다. 하나는 보안 폴더나 듀얼 앱 같은 다른 사용자 공간(사용자 150)에 함께 깔린 것이다.

### 2~4단계 결과 (2026-11-09 밤, 성범: "묻지 말고 끝까지, 서버 백업만 빼고")

- **화면 끝까지 배경(2단계)**: 페이지에 이미 `viewport-fit=cover`가 있고 폰 WebView가 156이라, Capacitor 8 SystemBars가 시스템 막대 높이를 그대로 넘겨 준다. 앨범 색과 재생 시트가 상태 표시줄 뒤까지, 목록이 아래 막대 뒤까지 깔리는 것을 폰에서 확인했다. `capacitor.config.json`의 `SystemBars`에 `style: DARK`(막대 아이콘 흰색)를 넣었다. CSS는 `--safe-area-inset-*`(앱)과 `env()`(브라우저)를 같이 읽는 `--top`, `--bot`을 쓴다.
- **새 디자인(3단계)**: `spikes/episode-01/app/template.html`을 Figma 시안대로 다시 짰다. 홈 머리 줄(프로필, Hi, Seongbeom, 설정), 영어 화면 글자, 화면 너비 미니 플레이어(처음 실행엔 없음), 위 8 띄운 재생 시트(모서리 24, 손잡이 36x4), 가사 18/21/24 세 단계(돋보기, 설정, 기억), 흐림 대신 38%, 더보기 시트(Repeat Album·One·Off, Korean translation은 팟캐스트만, Sleep timer), 취침 타이머 시트, 트랙리스트 바텀시트(구분선, 다 들음 표시 없음), 설정 화면(Playback, About), 가사 글자 크기 시트, 인터넷 없음 알림 띠를 넣었다. 재생 속도 기능은 뺐다.
  - `작성자 판단`: 소리가 앱 안에 들어 있어서 설정의 Downloads 섹션은 R2로 옮길 때까지 숨겼다. Account도 숨김. Voice credits는 줄 오른쪽에 ElevenLabs만 쓰고, 그 아래에 글꼴·아이콘 라이선스 한 줄을 뒀다. 심화·고급 앨범 설명은 영어로 새로 썼다(The past, plans, offers and requests / Say what you think, at length and naturally). 돋보기를 누르면 'Lyrics: Large'처럼 잠깐 알린다.
- **뒤로 가기**: Capacitor 앱은 뒤로 가기 한 번에 앱이 닫혔다. `@capacitor/app`을 붙여, 시트와 화면을 하나씩 닫고, 홈에서 재생 중이면 앱을 닫지 않고 내리고(소리 계속), 멈춰 있으면 'Press back again to exit.' 뒤 한 번 더 누르면 닫는다. 브라우저(Vercel)는 예전 막이 방식 그대로다.
- **백그라운드 재생(4단계)**: `@capgo/capacitor-media-session` 8.1.8(Capacitor 8용)을 붙였다. 재생하면 미디어 재생 포그라운드 서비스가 앱을 살려 두고, 알림창과 잠금 화면에 앨범 커버와 이전·재생·다음이 뜬다. 매니페스트에 `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `POST_NOTIFICATIONS`, `WAKE_LOCK`을 넣었고, `MainActivity`가 처음 실행 때 알림 권한을 묻고, 앱이 내려가도 WebView 타이머를 멈추지 않는다. 폰 확인: 화면을 끈 채(Dozing) 4화가 끝나고 5화가 저절로 이어졌고, 한 화 반복도 화면 꺼진 채 이어졌고, 이어폰 일시정지 키가 먹었다. 소리는 앱 안 파일이라 인터넷이 없어도 넘어간다. 운동 중 1시간 이상 듣기 시험은 성범이 직접 한다.
- 웹(Vercel `iyagi-english`)에도 같은 화면을 올렸다(2026-11-09 밤).
- 시험하면서 폰 화면 꺼짐 시간을 1분에서 30분으로 바꿨다가 끝나고 1분으로 되돌렸다.
- 남은 것: 5단계 R2(지금은 소리를 앱 안에 둬도 됨), 6단계 로그인(나중), 7단계는 지금 APK로 끝(`side-a`에서 `npm run apk`, 화면을 바꾸면 다시 설치).

## 3. 다시 확인할 정책 (작업 전에 최신 내용을 다시 본다)

내가 알고 있는 내용은 2026년 6월 기준이라 바뀌었을 수 있다. 해당 단계 시작 전에 공식 문서로 다시 확인한다.

- **일레븐랩스 음성 사용 범위**: 성범 요금제에서 만든 음성을 앱에 넣어 남에게 나눠도 되는지(무료 요금제는 출처 표기와 비상업 조건이 있다). A(혼자 쓰기)면 문제없고, B면 꼭 확인.
- **팟캐스트 앨범의 실존 인물**: 드레이크, 켄드릭 같은 실제 가수 이름과, 커버 그림의 사람 얼굴. 혼자 듣는 데는 괜찮지만, 플레이스토어에 올리면 초상권·상표와 Google Play 지식재산권·사칭 정책에 걸릴 수 있다. B로 가면 커버와 제목을 다시 본다.
- **Google Play 신규 개인 개발자 규칙** (B만): 등록비, 정식 출시 전 비공개 테스트(최근 기준 테스터 12명이 14일), 최소 타깃 안드로이드 버전.
- **안드로이드 개발자 인증**: 구글이 2026년부터 나라별로, 플레이스토어 밖에서 까는 앱도 인증된 개발자 것만 깔리게 바꾸는 중이다. 한국 적용 시기를 확인한다. A(직접 설치)에도 영향이 있을 수 있다.
- **백그라운드 재생 권한**: 안드로이드 14 이상은 미디어 재생용 포그라운드 서비스를 선언해야 하고, 13 이상은 알림 권한을 물어야 재생 알림이 보인다. 갤럭시 절전 설정이 재생을 끊지 않는지도 본다.
- **구글 로그인**: OAuth 동의 화면 테스트 모드(테스트 사용자만 로그인 가능)로 충분한지. B로 가면 개인정보처리방침 주소와 계정 삭제 방법(앱 안과 웹)을 갖춰야 한다.
- **무료 범위**: R2 저장 10GB(다른 앱이 3.25GB 사용 중), Firebase 무료(Spark) 한도(Firestore 하루 읽기 5만, 쓰기 2만), Blaze로 올리지 않기. 돈이 나가는 설정은 성범에게 먼저 묻는다.
- **글꼴과 아이콘**: Pretendard(OFL), Lucide(ISC)는 앱에 넣어도 된다. 앱 안 정보 화면에 라이선스를 적는다.
