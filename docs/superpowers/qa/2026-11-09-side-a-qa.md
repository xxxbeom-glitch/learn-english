## C. 문서가 옛 내용 (앱이 최신 결정대로)

- 설계 538: 토스트가 위쪽 → 지금은 아래(미니 위 24px).
- 설계 469·477·478·541: 들으면 저절로 받기·다음 화 미리 받기 → 지금은 앨범 받기 단추로만.
- 설계 532: 지우면 "들으면 다시 받는다" 안내 → 저절로 받지 않는 정책과 어긋남.
- 설계 481: 미니 플레이어가 가운데 알약(시간 표시) → 지금은 화면 너비 막대, 시간 없음.
- 설계 485·486: 재생 화면 배속 버튼, 오른쪽 반복 아이콘 → 지금은 돋보기·더보기 시트.
- 설계 484: 가사 흐림에 번짐 → 지금은 번짐 없이 38%.
- 설계 490: 뒤로 가기 토스트가 한국어, 재생 중 토스트 → 앱은 영어, 재생 중이면 앱을 내림.
- 설계 518: 로그인 전 Account 숨김, 한국어 문구 → 앱은 영어 Sign in을 보이고 누르면 안내.
- 팟캐스트 설계 6장(지금은 `docs/superpowers/specs/archive/2026-11-09-podcast-album-design.md`): 트랙 번호, 보라·진홍 색, 한국어 설명, '부'로 셈, 마이크·타샤 이름표, 재생 속도 → 앱은 EP 제목, 커버 갈색, 영어 설명, 이름표 없음, 속도 없음.
- 코드 주석: 101줄(번호, 높이 52), 126줄(글자 크기 슬라이더), 390줄('부'), 913줄(웹이 다음 화 받기).

## D. 확인해서 맞는 것

설정 섹션 구성, 앨범 받기 단추와 고리(취소, 다른 앨범 받는 중, 다 받으면 숨김), 한국어 제목·묶음 이름은 앨범 목록에만, 팟캐스트 EP 제목, 미니 좌우 밀기, 반복(전체 → 한 화 → 끔)과 다음 화 자동 재생, 더보기의 Korean translation은 팟캐스트만, 취침 타이머 선택지와 체크, 가사 18/21/24와 돋보기, 토스트 9종 위치, 오프라인 띠 문구, 앨범 색과 `#1ED760`, Figma 재생 화면·더보기·취침 타이머·설정·앨범과 화면 구성 일치.
