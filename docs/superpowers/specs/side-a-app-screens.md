# Side A 앱 화면과 디자인 시스템

목차는 [2026-11-07-story-audio-english-design.md](2026-11-07-story-audio-english-design.md). 저장, 소리 받기, 배포, 네이티브 앱은 [side-a-app-delivery.md](side-a-app-delivery.md). 화면 코드는 `spikes/episode-01/app/template.html`. 화면은 Figma 'EN-AudioBook' 시안(2026-11-09 디자인 개편)을 따르고, 반영 기록과 `작성자 판단`은 `docs/archive/plans/2026-11-09-side-a-android-app.md`의 '2~4단계 결과'에 있다.

UI 아이콘은 Lucide만 쓴다. 새 화면은 Taste Skill로 만들고, 완성 후 Impeccable은 검수만 한다.

## 1. 전체 방향 (2026-11-09)

- 스포티파이, 애플 뮤직 같은 음악 앱 모양. 첫 화면은 앨범 선반, 스크립트는 실시간 가사 화면처럼. 과정 하나가 앨범 한 장이고 앨범은 계속 늘어난다.
- 앱 이름은 **Side A**(카세트·LP의 A면). 스토어에 올리지 않고 이름 겹침은 따지지 않는다. 옛 이름 "이야기 영어"는 작업 이름으로만 남는다.
- 화면 글자는 영어로 쓴다. 한국어는 한국어 해설, 팟캐스트·쉐도잉의 한국어 해석 줄, 앨범 화면과 트랙 목록의 한국어 제목만. 예: 섹션 Basic Expressions, Podcasts, Shadowing, Words. 코스 Beginner, Intermediate, Advanced. 'N episodes · 100 min · N played'(앨범 길이는 총 분으로만), 'Coming soon'.
- 앱 아이콘: Figma 와이어프레임 페이지의 'app icon'(1024, 검정 바탕에 초록 세로 막대 소리 모양). 안드로이드용 '앞 그림(투명, 막대 56%)', '바탕(검정)', '원형 미리보기'를 1024로 내보내 Capacitor 아이콘 도구에 넣는다.

## 2. 홈

- 맨 위 한 줄: 프로필 사진(원 48, Figma `profile` 프레임 사진 → `app/cover-profile.webp`, 없으면 회색 #5a5a5a 원에 Lucide user 28), 인사말 "Hi, Seongbeom"(Display 20), 오른쪽 끝 설정 아이콘(Lucide settings 20). 줄 위는 상태 표시줄 아래 24, 줄 아래 첫 섹션 제목까지 32. 앱바는 메뉴가 3개쯤 모이면 다시 검토한다. → **2026-11-13 성범 결정: 하단 앱바(탭)를 둔다. 메뉴는 Library(지금의 홈), Game, Settings.** 설정이 탭으로 가므로 시안에서는 홈 오른쪽 위 설정 아이콘을 숨겼다(`작성자 판단`). **2026-11-13 앱에 넣음:** 홈 오른쪽 위 설정 아이콘을 뺐고 하단 탭으로 설정에 간다. 자세한 것은 6장 '앱 개발 1단계'.
- 섹션 제목 아래에 앨범 카드를 가로로 넘겨 보는 줄. 섹션 순서: Basic Expressions, Podcasts, Shadowing, Words. 카드 폭을 넘는 이름은 한 줄로 두고 끝을 ...으로. Coming soon 카드는 눌러도 반응이 없다. 준비 중 앨범도 커버를 흐리게 하지 않는다.
- **Play all (2026-11-10):** 섹션 제목 줄 오른쪽 끝 'Play all'(Head, 흰색 70%). 그 섹션의 음성 있는 화를 앨범 차례대로(다시 듣기용 다른 버전은 뺌) 처음부터 이어 튼다. 재생 화면은 열지 않고 미니 플레이어로 듣는다. 이전·다음과 자동 넘김도 이 순서이고, 섹션 끝에서 전체 반복이면 섹션 첫 화로. 트랙을 직접 고르거나 앨범 재생을 누르면 그 앨범 안으로 돌아간다. 섹션 순서는 저장하지 않는다(`작성자 판단`). 섹션을 듣는 동안 트랙 목록 시트는 섹션 전체(제목은 섹션 이름, 아래 줄은 전체 화 수와 길이, 앨범 이름을 작은 머리글로)를 보이고, 재생 화면 제목 아래 줄에도 섹션 이름을 쓴다.
- 처음 실행(들은 화 없음)에는 미니 플레이어가 없다. 홈과 앨범 목록은 맨 아래에 하단 탭과 미니 플레이어 높이만큼 여백을 둔다.

## 3. 앨범 화면

- 앨범 색에서 검게 내려가는 바탕, 가운데 큰 커버(200, 모서리 4), 앨범 이름·설명·"N episodes · 시간 · N played", 오른쪽 큰 재생 버튼(초록), 그 아래 화 목록.
- 화 목록 한 줄: 제목(Head)과 그 아래 한국어 제목(Caption 굵기 보통, 예: '나에 대해 말하기'), 오른쪽 끝 재생 시간. 줄 높이 약 47(위아래 6). 목차 묶음이 시작하는 자리에 묶음 이름을 Caption 대문자로. 팟캐스트 제목은 `EP1: 영어 제목`, 한국어 제목은 잡지 기사 제목처럼. 트랙 번호, 등장인물 이름, 다 들음 체크는 두지 않는다. 지금 듣는 화는 제목이 초록.
- 머리 줄 오른쪽 끝에 앨범 전체 받기 단추(Lucide arrow-down-to-line). 누르면 둥근 진행 막대(바탕 고리 흰색 20%, 받은 만큼 초록), 받는 중 다시 누르면 멈춤, 다 받은 앨범은 숨김. 동작은 [저장과 배포](side-a-app-delivery.md).
- 표지 흐려짐(2026-11-10): 올리기 시작하자마자 표지가 조금 작아지며 흐려지고, 아래 끝이 상태 표시줄 띠에 닿을 때 다 사라진다. 띠 바탕색은 비운다.

## 4. 재생 화면

- 위에서 8px 띄운 바텀시트(위 좌우 모서리 24). 손잡이를 누르거나, 위쪽을 아래로 쓸거나, 뒤로 가기로 닫는다. 배경은 앨범 커버 색에서 어둡게 내려가고 검은 딤을 깐다.
- 위쪽: 손잡이, 왼쪽에 앨범 커버(52)·곡 이름·앨범 이름(흰색 60%), 오른쪽 더보기(…).
- 아래: 재생 바(구간 표시 없음), 시간, 왼쪽 돋보기(zoom-in, 가사 글자 크기), 이전·재생·다음(재생 버튼은 흰색), 오른쪽 트랙리스트 아이콘. 재생 속도, 5초 건너뛰기, 볼륨 슬라이더, 재생 설정 창, 챕터 기능, 문장 반복 버튼은 없다.
- 트랙리스트는 재생 화면 위로 올라오는 바텀시트. 줄 사이 흰색 8% 구분선, 영어 제목 아래 한국어 제목을 작게. 지금 화를 누르면 가사로, 다른 화를 누르면 그 화를 튼다.
- 화를 열거나 고르면 언제나 처음부터 재생한다. 이전·다음은 화를 옮기고 멈춤 상태에서도 그 화 처음부터 자동 재생한다. 한 화가 끝나면 반복이 꺼져 있어도 다음 화로 넘어간다. 이전·다음과 자동 넘김은 같은 앨범 안에서만(Play all 중에는 섹션 안에서).
- **더보기 시트:** Repeat(누를 때마다 전체 반복 → 한 화 반복 → 반복 끔. 마지막 화가 끝나면 전체 반복일 때만 1화로, 꺼짐이면 멈춤. 꺼짐은 아이콘 40%), Lyrics(English + Korean, English only, Korean only 고르는 시트, 팟캐스트에서만. 2026-11-11 옛 Korean translation 스위치를 바꿈), Sleep timer(>, 다음 시트). 다음 시트는 지금 시트가 내려가고 다음 시트가 올라온다. 뒤로 가기는 앞 시트로. Sleep timer: Off, 15/30/45/60 min, End of episode. 정한 시간에 그냥 멈추고, 타이머 표시는 어디에도 없다.
- 가사를 보는 동안 화면이 꺼지지 않는다(Wake Lock). 트랙리스트로 바꾸거나 닫거나 앱을 내리면 풀린다.

### 가사

- 애플 뮤직처럼 굵게 왼쪽 정렬. 지금 줄만 또렷하고 나머지는 투명도 38%(흐림 효과 없음). 지금 줄은 가사 영역 위에서 22% 높이. 손으로 스크롤하면 6초 뒤 지금 줄로 돌아온다. 문장을 누르면 그 문장으로 간다.
- 구간 제목은 없고 구간이 바뀌는 곳에 넓은 간격만. 말하는 사람 이름표는 코스에는 없고, 쉐도잉 대화 줄에만 붙인다([쉐도잉](side-a-shadowing.md)).
- 해설 줄은 쉼표·마침표·물음표 뒤 마디에서 줄이 바뀌도록 감싼다("라는", "라고" 앞에서는 끊지 않는다). 손으로 넣은 줄바꿈은 없다.
- 말해보기: 한국어 문제와 영어 정답은 붙여 한 쌍으로, 둘 다 오른쪽 정렬, 쌍 사이와 안내 해설과 첫 문제 사이는 넓게. 정답은 나오기 전에는 줄 자체가 없다가 정답 음성이 나오면 생긴다(2026-11-10). 정답 아래 한글 뜻은 없다. 멈추는 동안 한국어 문제 줄이 밝게 남는다(멈춤 줄 표시는 없음).
- 대본만 있는 화(음성 준비 중): 앨범 이름 자리에 'Beginner · Script only', 소리 없이 읽는 속도로 줄을 짚고, 지금 줄이 아닌 줄도 75%로 읽히게 둔다.
- 팟캐스트: 영어 줄 아래 한국어 해석(Body)을 붙인다.
- 글자 크기 3단계: Default 18, Large 21, Extra large 24. 돋보기를 누를 때마다 차례로 바뀌고(24 다음 18) 기억한다. 설정에서도 고친다. 줄 높이 150%, 문단 사이 16.

## 5. 미니 플레이어

## 6. 설정 (Figma 07)

- iOS 설정처럼 섹션별 묶음 목록. 머리 줄은 왼쪽 44, 가운데 제목, 오른쪽 44 — 다른 화면 머리 줄도 이 틀. 설정은 2026-11-13부터 하단 탭의 첫 화면이라 뒤로 버튼이 없다(제목만). 섹션 이름 Caption 대문자, 묶음 바탕 bg/sheet, 모서리 12, 줄 높이 48, 줄 사이 왼쪽 16 띄운 흰색 8% 구분선, 묶음 아래 설명 Sub. 되돌릴 수 없는 줄은 text/danger #ff453a. 글자는 영어.
- **Account**(맨 위): 구글 계정 로그인으로 화별 들은 위치, 다 들은 화, 들은 시간을 저장해 재설치나 폰 교체에도 잇는다. 로그인 전 '로그인' + '구글 계정으로 들은 기록을 저장해요' + 화살표, 로그인 뒤 이름과 'Signed in with Google', 그 아래 Sign out(Figma 07b). 서버는 Firebase. **나중에 붙인다.** 첫 앱은 기록을 폰 안에만 두고 Account 섹션은 숨긴다.
- **Notifications:** Push notifications 스위치(새 화가 올라오면). 실제 보내기는 아직 없다.
- **Playback:** Lyrics text size(시트), Podcast lyrics(시트, 더보기의 Lyrics와 같은 값).
- **Downloads (2026-11-13 성범 "앨범별 다운로드 기능 빼고 차라리 설정에서 음성데이터 전부 받기, 삭제하기"):** Wi-Fi only, **Download all audio**, Storage used, Delete downloads(확인 창 09: Cancel, 빨간 Delete, 들은 기록은 남음). 앨범 화면 오른쪽 위의 받기 단추와 둥근 진행 표시는 없앴다. Download all audio 한 줄이 모든 화의 소리, 쉐도잉 한국어 해설, 문장 게임 소리(모두 1,724개, 약 91MB)를 받는다. 줄의 모습: 받기 전 오른쪽에 전체 크기('91 MB'), 받는 중 제목 'Downloading'과 '42% · Cancel'(누르면 멈춤, 다시 누르면 받은 데부터 이어 받음), 다 받으면 'All audio downloaded'와 초록 체크. 앱이 새 판이 되어 소리가 늘면 다시 'Download all audio'가 된다. Delete downloads는 받은 소리를 모두 지운다. 줄의 글과 모습은 시안 없이 만든 것이다(`작성자 판단`).
- **About:** Version만 둔다. Voice credits 줄은 2026-11-13 성범 요청으로 뺐다. 내용 판 번호를 보이는 줄도 넣지 않는다(Figma `27b 설정 탭`).
- **앱 개발 1단계 (2026-11-13, 폰용 APK까지 빌드. 아래 '게임 방향'의 긴 기록보다 이 묶음이 지금 앱의 모습이다):**
  - **하단 탭:** Library(옛 홈, Lucide disc-3), Game(gamepad-2), Settings(settings). 바탕 `var(--bar)` #181818, 탭 60 + 시스템 버튼 줄(safe-area). 앨범 화면에서도 보이고 Library가 켜진 채다. 앨범에서 Library를 누르면 홈으로 간다. 안드로이드 뒤로 가기는 Game·Settings 탭에서 Library로 간다(`작성자 판단`). 재생 화면과 시트는 탭을 덮는다.
  - **Game 탭 화면:** Figma 21~26과 같다. 헤더(제목 Game, 왼쪽 속도, 오른쪽 건너뛰기), 문제 카드(경계에 걸친 듣기 버튼, Replay 0/3, 밑줄 빈칸), 단어 모음, Check, 맞음 판(딤, 정답 문장과 뜻, Next), 결과(Round complete, First try, Time, Level, Play again). 결과 화면에는 헤더가 없다. Game 탭에는 미니 플레이어가 없다.

## 7. 알림과 상태

- 토스트는 화면 위쪽 머리 줄 높이 가운데에 위에서 내려온다.
- 인터넷 없음(10): 받아 두지 않은 화를 인터넷 없이 틀면 재생 바 위에 흰 알림 띠 "You're offline. This episode isn't downloaded yet."(재생 화면이 닫혀 있으면 같은 말을 토스트로). 연결 상태 값이 아니라 소리를 실제로 못 받았는지를 보고 띄운다(앱 안 브라우저는 비행기 모드에서도 연결됨으로 답할 때가 있다).
- 뒤로 가기: 재생 중 홈에서 뒤로 가기를 눌러도 앱을 닫지 않고 "재생 중이라 닫지 않았어요. 홈 버튼으로 나가면 계속 들려요."를 띄운다. 재생 중이 아니면 "뒤로 가기를 한 번 더 누르면 닫혀요." 후 한 번 더 누르면 닫힌다.
- 끝에서 당겨도 화면이 늘어나지 않게 한다(안드로이드 늘어남 효과 끔).
- 시작 화면(11): 검정 바탕 가운데 앱 아이콘 막대(초록 타원 9개). 왼쪽 타원부터 0.11초 간격으로 오른쪽에서 들어와 모이고(각 1초), 쉰 뒤 왼쪽부터 위아래로 한 번 출렁이고(각 0.7초), 살짝 커지며 0.5초에 홈으로 사라진다(약 4.2초). 안드로이드 기본 시작 화면은 검정 바탕만, 애니메이션은 `template.html`의 `.intro`.
- 폰 잠금 화면과 알림창 재생 컨트롤에 앨범 커버를 띄운다(안드로이드가 그리므로 시안 없음).
- **PIP 작은 창 (2026-11-12 성범 요청, 시안 없음):** 재생 중에 홈으로 나가면 유튜브처럼 작은 창이 뜨고 가사만 보인다. 창 비율은 유튜브와 같은 16:9(처음 2:1은 창이 낮아 단추가 가사를 다 가려서 바꿨다), 바탕은 앨범 색이 아래로 어두워지는 그라데이션(재생 화면과 같은 색), 맨 아래 얇은 진행 선. 재생 화면처럼 대본 전체를 깔고 지금 줄이 창 위쪽에 오도록 세로로 민다. 지금 줄은 밝게, 나머지는 흐리게(재생 화면과 같은 규칙). 글자 크기는 줄 길이와 상관없이 같다: 영어 줄 Outfit Bold 창 폭의 6%, 한글 뜻 4.2%. 화자 이름, 가사 표시 설정(영어만, 한글만), 정답 가리기도 재생 화면 가사를 그대로 따른다. 아주 긴 줄은 한글 뜻이 창 아래로 넘어갈 수 있다. 창을 누르면 안드로이드가 이전, 재생/멈춤, 다음 단추(Lucide 모양)를 띄운다. 단추의 크기와 자리는 안드로이드(갤럭시)가 정해서 앱이 바꿀 수 없다. 창 안의 가사는 누르거나 손으로 밀 수 없다(안드로이드 제한). 멈춰 있을 때는 홈으로 나가도 창이 뜨지 않는다. 창을 밀어 닫아도 소리는 이어지고 알림창에서 멈춘다. 만든 방법은 `side-a-app-delivery.md` 6장. 옛(같은 날 첫 판): 지금 줄 하나만 보이고 긴 줄은 글자를 줄였다. 글자 크기가 줄마다 바뀌어 보여서 성범 제안으로 전체 가사 스크롤로 바꿨다.
