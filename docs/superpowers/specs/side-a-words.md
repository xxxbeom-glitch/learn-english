# Side A Words: 단어 오디오북 (2026-11-10)

목차는 [2026-11-07-story-audio-english-design.md](2026-11-07-story-audio-english-design.md). 공통 규칙 [side-a-rules.md](side-a-rules.md), 음성 [side-a-voice.md](side-a-voice.md).

단어장을 화면 카드가 아니라 귀로 듣는 앨범으로 만든다. 11-10 새벽 성범이 "단어장도 오디오북 형태로 한다면"이라고 물어 짠 초안을, 같은 날 "챕터1만 한번 진행해보자"로 1화를 만들었다.

## 1. 전체 짜임 (`제안`, 숫자는 단어 목록을 뽑으면 다시 센다)

- 대본에 나온 단어(약 550개)에 Longman 말하기 빈도 S1~S2를 합친 약 2,000단어.
- 많이 쓰는 순서로 500단어씩 앨범 4개(Words 1~4), 앨범마다 25화, 한 화에 단어 20개. 앨범 안에서 20개씩 주제(하루 일과, 음식, 감정, 이동 등)로 묶는다.
- 한 화에 한 단어씩은 하지 않는다(곡이 너무 짧고 수백 곡이 된다).

## 2. 한 화의 흐름

```text
시작음 → 도입(해설자 한 줄) → 단어 20개 → 복습 → 끝인사(끝음)
한 단어: 클릭음 → 단어(영어) → 뜻(해설자) → 예문(다른 영어 목소리) → 예문 뜻(해설자) → 단어 세 번
복습: 해설자가 한국어 뜻 → 2초 멈춤 → 영어 단어, 문제 사이에 클릭음
```

- 뜻은 "'잠에서 깨다'라는 뜻이에요"처럼 작은따옴표 인용.
- 목소리: 단어는 남1과 여2, 예문은 여1과 남2를 번갈아 쓴다. 단어를 다시 들려줄 때와 복습 답은 처음 만든 단어 조각을 다시 쓴다. (`작성자 판단`)
- 예문 뒤 단어는 세 번, 사이 1.2초("너무 빨리 말하는 기계 같다"). 단어와 단어 사이는 2초.
- **불규칙 꼴:** 미래형과 -ed 규칙 과거형은 넣지 않는다(코스에서 패턴으로 배운다). 불규칙 과거형(wake up → woke up, eat → ate)만 뜻 뒤에 "과거형은 ○○라고 해요." 한 줄을 붙이고, 예문도 과거 문장으로 하고, 마지막에 "eat, ate"처럼 두 꼴을 들려준다. 불규칙 복수형(person → people)도 같다.
- **예문:** 코스 대본에 그 단어가 나온 문장이 있으면 먼저 쓰고, 없으면 지금 대본 규칙대로 새로 쓴다.

## 3. 앱 (2026-11-10 "앱에 넣어")

> **지금 상태: 앱에서 뺐다 (2026-11-10 성범 "words는 일단 앱에서 제거해줘").** 템플릿 `WORDS` 목록을 비우고(항목은 주석으로 남김) `build_page.py`의 `WORDS_IN_APP = False`로 화를 넣지 않는다. 빈 선반은 홈에 그리지 않아 Words 선반도 안 보인다. 대본, 음성, R2 소리는 그대로 두었다. 다시 넣을 때는 두 곳을 되돌리면 되고, 아래 내용은 그때의 설계다. 맨 뒤 트랙이라 빼도 앞 트랙의 들은 기록 자리 번호는 밀리지 않는다.

- 홈 맨 아래 Words 선반, 앨범 'Words 1'(템플릿 `WORDS`, 이름 열쇠 '단어 1', 글자 표지 W1, 바탕 #1d5c63. 색과 소개 문구는 `작성자 판단`). 트랙 이름에 EP 번호를 붙이지 않는다.
- 가사는 영어 줄과 해설 줄을 그대로 보인다. 단어와 예문 아래 한글 뜻은 없다(바로 다음 해설이 말한다). 단어 묶음 사이는 56px로 띄운다(선은 넣지 않는다).
- 복습은 말해보기처럼 한국어 문제를 오른쪽에 두고, 영어 답은 소리가 나올 때 생긴다(답 아래 뜻 없음).
- 들은 기록 자리 번호가 밀리지 않게 쉐도잉 뒤에 붙인다.

## 4. 파일과 만드는 법

- 대본 `content/stories/words-NN.md`(앨범마다 한 파일, 지금 `words-01.md`).
- 음성 `spikes/episode-01/build_words.py`(`clips`, `build`). 결과 `audio/words/epNN/w1-NN.mp3`, 앱용 `w1-NN.webm`, timeline.json.
- 조각 앞뒤 페이드와 SKIP(조각 앞 잘라 내기)은 [음성](side-a-voice.md) 3장. 1화 wake up 조각(e03) 앞 0.155초를 잘랐다. 다른 '삑'은 소리 모양으로 가려지지 않아 성범이 들리는 곳을 알려 주면 같은 방법으로 자른다.
