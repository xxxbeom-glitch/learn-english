## 수집 메모

- 방법: 로그인 없이 앱 내장 브라우저로 pinterest.com 검색 결과를 보고 핀 링크를 기록했어요.
- 검색어: language learning app ui, vocabulary app design, neo brutalism mobile app, swiss typography mobile app, japanese minimal app ui, journal app ui warm paper.
- 표기: 별도 표시가 없으면 Pinterest에 올라온 시안·컨셉 작품이에요. 실제 출시 앱 화면이나 소개는 `[출시 앱]`으로 표시했어요.
- 제외: 말해보카 화면, 보라색 중심 화면.
- 한계: 마지막 묶음(저널·종이 느낌)은 화면 캡처가 오류로 나오지 않아 핀 제목과 설명만 보고 적었어요. 시각 요소는 제목에서 짐작한 것이라 확정이 아니에요.
- 일부 핀은 제목이 비어 있어 보이는 모습으로 짧게 설명했어요.
