# Mobbin 디자인 컨셉 레퍼런스

개인용 영어 어휘 학습 앱(갤럭시, 한글 뜻 보고 빈칸에 직접 쓰기, 압박 없는 느낌)을 위해 모은 시각 컨셉 레퍼런스예요. 방향을 좁히지 않고 조용한 것부터 대담한 것까지 넓게 모았어요.

- 수집 방식은 Mobbin 화면 검색이고, 결과 이미지를 직접 보고 적었어요. 이미지는 내려받지 않고 링크만 남겼어요.
- 검색 도구가 iOS와 웹만 지원해서 안드로이드 화면은 찾지 못했어요. 전부 iOS 화면이에요.
- 말해보카 화면과 보라색 중심 화면은 뺐어요. 앱 하나당 한 항목만 넣었어요.
- 구성과 분위기만 참고하고 외형은 베끼지 않아요.
- 항목 형식은 `앱 | 화면 종류 | 눈에 띄는 시각 요소 | 색 인상 | 이 앱에 쓸 만한 점`이에요.
