# 유아이볼 디자인 컨셉 레퍼런스

개인용 영어 어휘 학습 앱(갤럭시, 한글 뜻 보고 영어 문장 빈칸에 직접 쓰기)을 위한 시각 컨셉 모음이에요. 아직 방향을 좁히지 않고 폭넓게 모으는 단계예요.

- 형식: `앱 이름 — 화면 종류 | 눈에 띄는 시각 요소 | 색 인상 | 이 앱에 쓸 만한 점`
- 이미지는 내려받지 않고 링크만 남겼어요. 검색 결과 이미지를 직접 보고 적었어요.
- 말해보카 화면과 보라색 중심 화면은 제외했어요. 외형을 베끼지 않고 구성과 분위기만 참고해요.
- 수집 현황: 서로 다른 앱 51개. 목표(80개)에는 못 미쳐요. 결과 한 번에 이미지가 3~8장만 와서 호출 수 대비 수확이 적었어요. 부족분은 다음 라운드에서 채울 수 있어요.
- 일부 항목은 한 번에 여러 결과 이미지가 같이 와서 앱과 이미지를 순서로 맞췄어요. 링크를 열어 확인해 주세요.
- 아직 덜 본 영역: 음악, 패션, 독서 앱의 본문 화면, 바텀시트, 채팅, 결과 화면. 이 영역은 다음에 더 찾아야 해요.
